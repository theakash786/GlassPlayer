# GlassPlayer 🎵
A simple, web-based music player with a glassmorphism UI. It allows users to play local audio files directly from their device storage.

🚀 **Live Demo:** [Click here to use GlassPlayer](https://theakash786.github.io/GlassPlayer/)

## Features
* Clean Glassmorphism Design
* Local File Upload (No server storage, completely private)
* Live Progress Bar & Duration Tracker
* Auto-stop on song completion
